## Decisions
- **Integration branch:** the cloud harness only allows pushing to `claude/gallant-cray-mdaoqn`, so that
  branch plays the role of `main`. Milestone branches `m<N>-<name>` are local and squash-merged into it.
  Merge it into `main` on GitHub when you're happy (or tell me to).
- Added small libs: `react-router-dom` (routes), `@fontsource/ibm-plex-sans|mono` (bundled fonts),
  `python-multipart` (FastAPI uploads), `jsdom` (vitest env).
- Backend port in dev is 8765 (Vite proxies `/api`). Launcher (M8) picks a free port.
- Map nodes show status as a coloured dot + text label; "Not started" nodes show only the outline dot
  (default state; avoids 100 identical labels). The side panel always shows the text label.
- If only one of the two model slots is set, both features use that model.
- Single-chunk decks (≤ 12 slides) skip the merge LLM call; caps are still enforced in code.
- A top-level topic named like the lecture is lifted (its children move up a level).
- Map editor sync: rather than translating each Mind-Elixir operation, the client sends the full
  tree after any change (debounced 300 ms) and the server reconciles. Robust to undo/redo and drag.
- New nodes created in the editor get ULIDs client-side (`frontend/src/lib/ulid.ts`).
- "Add uncovered slides" adds one node per slide under the root, labelled by the slide title.
- AI node actions use the study model (they're small, frequent calls).
- Thread answers render as plain text (no Markdown library in SPEC §2).
- Follow-ups continue the selected exchange ("Follow up"); a new question starts a new exchange.
- Inbox suggestions are requested lazily when the inbox screen is open (capture stays < 1 s).
- Grading a blank answer is always "wrong" regardless of the model.
- Course-level practice items (Generate "unassigned") live in `courses/<id>/practice.json`
  (not in SPEC §3 layout; same shape as lecture practice.json).
- Generated summaries/explanations show an "AI-written · check it" tag too.
- UI deviations (small, deliberate): map hint chips add "Tab child · Enter sibling · F2 rename"
  (double-click opens Focus as the mockup says, so rename moved to F2); clicking the selected
  status again clears it to "Not started" (the 3-way control has no 4th button).
- Mockup PNGs couldn't be saved from chat; `docs/ui/README.md` lists the expected file names.
- Reminders with no date in the text need a date picked in the popover (no silent default).
- Pomodoro state lives in localStorage (per browser) — survives refresh; sessions are logged to
  `sessions.jsonl` when a focus block completes.
- From M8 on, milestone commits are pushed to the integration branch as-is (fast-forward) instead
  of one squash commit per milestone.
- Deleting a map node no longer asks for confirmation: it shows an Undo toast (UI.md §3.2) and
  Ctrl/Cmd+Z works. Threads/notes/cards of deleted nodes still move to the parent on the server.
- No release tag pushed from the cloud session (outward-facing); user tags when ready.
- Review: a session works on a snapshot of the queue taken at start; "Again" items reappear in the
  next session (not re-inserted mid-session). Today now shows the Due card (v0.2) since FSRS exists.
- "Last 3 recall results" in SPEC §5.14 = the node's last 3 rows in results.jsonl of any kind
  (Test me, blank-map recall, explain-back); each must be ≥ 80 %.
- Derived slide data (extracted text + thumbnails) cached at `courses/<id>/derived/<source_id>/`
  (rebuildable from the source file; not in SPEC §3 layout).
